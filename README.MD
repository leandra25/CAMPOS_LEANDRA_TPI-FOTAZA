#  Fotaza - Red Social de Publicaciones con Imágenes

## Descripción del proyecto

**Fotaza** es una aplicación web tipo red social donde los usuarios pueden registrarse, iniciar sesión y compartir publicaciones con imágenes.

Cada publicación puede incluir:
-  Una o varias imágenes
-  Comentarios de otros usuarios
-  Valoraciones (puntuación de 1 a 5 estrellas)

Además, los usuarios pueden:
- Seguir a otros usuarios
- Ver un feed con publicaciones de otras personas
- Gestionar su perfil
- Editar o eliminar sus publicaciones (borrado lógico)

---

##  Tecnologías utilizadas

- Node.js
- Express.js
- Sequelize (ORM)
- Postgres
- Pug (motor de plantillas)
- Express-session
- Bootstrap (UI)
- JavaScript (frontend y backend)
